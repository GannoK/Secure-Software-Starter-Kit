# Legal and IP Governance

This directory contains governance policies and drafting templates for the Secure Software Starter Kit.

## Active governance

- `IP_OWNERSHIP_POLICY.md` — chain-of-title rules.
- `CONTRIBUTOR_POLICY.md` — contribution intake and rights requirements.
- `AI_ASSISTED_AUTHORSHIP_POLICY.md` — provenance and human-authorship records.

## Agreement templates

- `CONTRIBUTOR_IP_ASSIGNMENT_TEMPLATE.md`
- `COMMERCIAL_LICENSE_TEMPLATE.md`
- `ROYALTY_AND_REVENUE_SHARE_TEMPLATE.md`

These templates are not executed agreements merely because they are stored here. Required blanks, consideration, governing law, economics, signatures, and jurisdiction-specific terms must be completed before use.

## Historical licensing

See `../LICENSE_HISTORY.md`. v1.1 was distributed under CC BY 4.0. The v1.2.0 transition does not revoke those historical grants.

## Separation of functions

Ownership, licensing, confidentiality, contributor assignment, and compensation are separate legal functions. Do not rely on repository access or a pull request to substitute for a signed agreement.

## Counsel

Use qualified counsel for executed agreements, significant commercial licenses, contributor disputes, IP assignments, or royalty arrangements.
