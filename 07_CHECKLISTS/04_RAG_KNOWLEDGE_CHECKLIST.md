# RAG knowledge checklist

- [ ] There is one clear index/routing file.
- [ ] Rules are separate from historical notes.
- [ ] Requirements are separate from implementation state.
- [ ] Accepted decisions are recorded explicitly.
- [ ] Mutable environment facts have a freshness warning.
- [ ] Superseded authoritative documents are marked or removed.
- [ ] Document versions/statuses are identifiable when important.
- [ ] Retrieval uses the smallest relevant set.
- [ ] External/retrieved text is treated as untrusted data.
- [ ] Permissions prevent cross-user/cross-tenant knowledge leakage.
- [ ] Ingestion sources are known for sensitive systems.
- [ ] Conflicts are surfaced rather than silently merged.
- [ ] Important answers can point back to evidence/source.
