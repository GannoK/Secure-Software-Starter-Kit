# ChatGPT setup checklist

- [ ] Global Custom Instructions contain only durable cross-project working preferences.
- [ ] A dedicated ChatGPT Project exists for the software.
- [ ] Project instructions define the project's RAG/evidence/change rules.
- [ ] `00_INDEX_AND_ROUTING.md` is present as the project knowledge entry point.
- [ ] Requirements, architecture, security, decisions, state, and tests are represented.
- [ ] Project memory mode was deliberately chosen.
- [ ] Sensitive/client projects use isolation appropriate to their data.
- [ ] Important state is stored in files, not only memory/chat history.
- [ ] The first chat uses the new-project or resume-project starter prompt.
- [ ] Consequential work uses bounded implementation + verification.
