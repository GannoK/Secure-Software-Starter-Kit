# Optional - ChatGPT Work

If ChatGPT Work is available on your plan/surface, it can carry out substantial multi-step work across files, tools, and supported apps.

Use it when you want ChatGPT to produce or modify substantial project artifacts.

Keep the same authority model:
- Project instructions define project behavior.
- Project knowledge defines requirements and boundaries.
- Live evidence overrides stale mutable state.
- Consequential actions still require appropriate approval.
- Finished artifacts still need review and verification.

Do not treat "Work completed the task" as equivalent to "the software is secure and correct." Review the actual changes and evidence.
