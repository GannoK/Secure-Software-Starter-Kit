# Five-minute setup

## Step 1 — Make a project folder

Create a folder for your software project.

Inside it, copy the entire folder:

`02_PROJECT_KNOWLEDGE_TEMPLATE`

Rename the copied folder to:

`PROJECT_KNOWLEDGE`

## Step 2 — Open the project with your AI assistant

If your AI product supports project files, a library, knowledge base, workspace, or attachments, make the `PROJECT_KNOWLEDGE` files available to it.

If it does not, you can paste the relevant files into the conversation when needed.

## Step 3 — Start with the index

Open:

`PROJECT_KNOWLEDGE/00_INDEX_AND_ROUTING.md`

Replace the bracketed examples with your project name and basic facts.

You do **not** need to fill everything in. Unknown is a valid answer.

## Step 4 — Paste the starter prompt

Use:

`03_PROMPTS/01_START_A_NEW_PROJECT.txt`

Paste it into the AI and then describe what you want to build in normal language.

## Step 5 — Do not start coding immediately

Ask the AI to help complete:
- project brief;
- requirements;
- security profile;
- initial architecture;
- threat model.

Then make the first small implementation slice.

## What success looks like

At any point, you should be able to answer:

1. What are we building?
2. What rules govern the work?
3. What has been decided?
4. What is verified?
5. What is still unknown?
6. What are we changing next?
7. How will we prove the change worked?
8. How can we undo it?
