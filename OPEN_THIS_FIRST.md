# OPEN THIS FIRST - Secure AI Software Starter Pack v1.1

**No programming experience is required to begin.**

This pack helps you use an AI assistant as a structured software-building partner without treating the AI as an unquestionable authority.

## The 10-minute path

1. Open `00_QUICK_START/QUICK_START_ONE_PAGE.pdf`.
2. Read `01_BEGINNER_GUIDE/02_FIVE_MINUTE_SETUP.md`.
3. Read `01_BEGINNER_GUIDE/06_CHOOSE_YOUR_ASSURANCE_PROFILE.md`.
4. Copy `02_PROJECT_KNOWLEDGE_TEMPLATE` into your software project and rename the copy `PROJECT_KNOWLEDGE`.
5. Fill in what you know. Write `UNKNOWN` when you do not know.
6. Give the AI `03_PROMPTS/01_START_A_NEW_PROJECT.txt`.
7. Build only the first small implementation slice.
8. Verify the result before continuing.
9. Update project state/tests with evidence.
10. Create a handoff before a long session ends.

## The core rule

**AI output is a proposal until evidence proves the relevant result.**

For consequential work, require:
- exact scope;
- assumptions;
- security impact;
- rollback/recovery;
- verification;
- explicit approval for destructive/production/high-privilege actions.

## Choose a profile

- STARTER - local learning/prototype.
- PRODUCTION - real users, internet exposure, or meaningful real data.
- HIGH ASSURANCE - high-impact systems where failure can cause severe harm.
