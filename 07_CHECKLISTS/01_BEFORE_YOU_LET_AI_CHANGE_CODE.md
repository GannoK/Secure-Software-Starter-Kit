# Before you let AI change code

- [ ] The requirement is clear.
- [ ] The AI retrieved the relevant project rules/context.
- [ ] Current state was checked.
- [ ] Assumptions are labeled.
- [ ] Exact scope is stated.
- [ ] Unrelated changes are excluded.
- [ ] Security implications were considered.
- [ ] Secrets will not be exposed.
- [ ] Rollback/recovery is understood.
- [ ] Tests are defined before declaring success.
- [ ] High-impact/destructive/production changes require explicit approval.
