# Contributing

Thank you for helping improve the Secure Software Starter Kit.

This project is intentionally beginner-friendly, but its security and engineering guidance should remain technically defensible. The project is now maintained under a proprietary IP model.

## Before opening a pull request

1. Keep the change focused and explain the problem it solves.
2. Distinguish observed facts from assumptions and recommendations.
3. Do not weaken a security boundary merely to make a workflow easier.
4. Prefer authoritative primary sources for standards and security claims.
5. Do not paste copyrighted standards text into the repository unless its license permits redistribution.
6. Check links, filenames, and cross-references.
7. Run `python tools/verify_repository.py` from the repository root.
8. Explain how you verified the change.
9. Disclose all third-party and pre-existing/background IP.
10. Ensure the applicable contributor, employment, contractor, or IP-assignment agreement is executed before substantive material is accepted as project-owned IP.

## AI-assisted contributions

AI assistance is allowed. The contributor remains responsible for reviewing, testing, sourcing, provenance, and licensing what they submit. Material AI assistance must be disclosed where required by `LEGAL/AI_ASSISTED_AUTHORSHIP_POLICY.md`.

## Contribution rights

Submitting a pull request, issue, patch, suggestion, or other material does **not** by itself:
- transfer copyright ownership;
- grant the project a commercial license;
- grant the contributor a royalty, revenue share, equity, or ownership interest; or
- create an obligation to accept or compensate the contribution.

Substantive contribution rights must be governed by an applicable signed agreement before acceptance.

## Pull requests

A good pull request should state:
- what changed;
- why it changed;
- security or assurance impact;
- evidence or references;
- verification performed;
- third-party/background IP;
- AI assistance where material;
- any remaining uncertainty.

See `LEGAL/CONTRIBUTOR_POLICY.md` and `LEGAL/CONTRIBUTOR_IP_ASSIGNMENT_TEMPLATE.md`.
