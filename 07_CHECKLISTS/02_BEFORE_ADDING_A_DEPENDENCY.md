# Before adding a dependency

- [ ] Package name independently verified.
- [ ] Official source/registry verified.
- [ ] Need for dependency justified.
- [ ] Project appears maintained.
- [ ] License considered.
- [ ] Known vulnerabilities reviewed.
- [ ] Permissions/capabilities understood.
- [ ] Version strategy chosen.
- [ ] Lockfile updated where applicable.
- [ ] Transitive dependency impact understood enough for project risk.
- [ ] Dependency will appear in SBOM/inventory.
