# Step 4 - Start the first ChatGPT project chat

Create a new chat **inside the project**.

Paste:

`03_PROMPTS/01_START_A_NEW_PROJECT.txt`

Describe the idea in ordinary language.

Then ask ChatGPT to help fill the project knowledge files.

## Recommended sequence

1. Project brief.
2. Requirements and acceptance tests.
3. Assurance profile.
4. Threat model.
5. Architecture.
6. First implementation slice.
7. Verification.
8. Update current-state/test files.
9. Continue with the next bounded slice.

## For an existing project

Use:

`03_PROMPTS/02_RESUME_AN_EXISTING_PROJECT.txt`

This tells ChatGPT to reconstruct authority and current state rather than treating the newest chat as a fresh project.
